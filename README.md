# Xevis Labels — Forge-мод для 1.12.2 (ники + голограммы)

Клиентский мод для Minecraft 1.12.2 (Forge): стилизованные ники над игроками
(без подложки, чистый текст с тенью) и парящие голограммы с ножкой-лучом
и свечением на земле. Дизайн задаётся на сайте-редакторе, в игру прилетает
по localhost-связи (⇄ Игра) или правится в `config/xevis.json`.
Никаких серверных данных не требует.

## Что внутри

- `label/WorldLabel` — билборд-плашки через `RenderManager` + `FontRenderer`:
  ник `префикс + имя + клан` + свободная вторая строка, всегда без фона.
- `label/PngPlates` — PNG-арт с сайта (`DynamicTexture`): пластина голограммы,
  ножка-луч от текста до земли, светящийся эллипс на земле, спрайт собственного
  ника. Приходят через `POST /xevis-png` с сайта (кнопки «Отправить PNG в игру»),
  хранятся в `config/xevis-*.png` и переживают перезапуск. V-ориентация —
  ванильная (ряд 0 канваса сверху, как у GUI-текстур и шрифта: v=0 сверху).
- `HoloCommand` (`/xeholo`) — установка голограмм в игре: `add` — новая здесь,
  `set <n>` — перенести, `del <n>` — удалить, `through <n>` — вкл/выкл
  видимость сквозь стены, `list` — список. Координаты
  хранятся в конфиге, стиль (текст/цвета/эффекты) — с сайта.
- Нике других игроков мод запекает PNG-спрайты сам (`WorldLabel.bakeNickSprite`,
  AWT, в стиле конфига, только на сессию — в `config/` не пишутся), поэтому
  все ники выглядят как PNG. Свой ник — спрайт с сайта (`nick0`).
  Фейковые игроки модов (Blockbuster), которых нет в `playerEntities`,
  добираются сканированием `loadedEntityList`. Своя подпись актёра
  Blockbuster (имя рекорда) рисуется самим Blockbuster мимо Forge-событий —
  её наш мод не трогает.
  Спрайты рисуются не крупнее нативного текста (автофит) и висят ниже
  над головой (+0.32 блока). Ориентация спрайтов правится с сайта:
  чипы «Флип V» (вкл) и «Зеркало U» (выкл) в блоке ника → `spriteFlipV` /
  `spriteMirrorU` в конфиге; скейл билбордов — ванильный (−,−,+).
- `ClientEvents` — гасит ванильные теги игроков
  (`RenderLivingEvent.Specials.Pre`, без миксинов и кор-модов) и дорисовывает
  свои ники + голограммы в `RenderWorldLastEvent`. Свой ник виден только
  от 3-го лица, крадущиеся/невидимые чужие теги скрыты, дальность — 64 блока.
- `XevisConfig` — `config/xevis.json` с ТЕМИ ЖЕ ключами, что у Fabric-версии:
  один файл конфига подходит обоим модам.
- `link/LinkServer` — localhost HTTP `127.0.0.1:25585`: `POST /xevis` применяет
  конфиг живьём, `POST /xevis-png?type=plate|beam|pad&slot=0` — PNG-арт.

## Сборка

**Рекомендую: через GitHub Actions, локально ничего ставить не нужно.**

1. Создай пустой репозиторий на GitHub.
2. Залей туда содержимое `xevis-forge-1.12.2.zip` (чтобы `build.gradle`
   лежал в корне репозитория, не во вложенной папке).
3. В репозитории нажми Add file → Create new file, введи имя
   `.github/workflows/build.yml` и вставь туда содержимое файла
   `build-forge-1.12.2.yml` (лежит рядом с архивом), Commit.
4. Вкладка Actions → дождись зелёной галочки (первый раз ~10 минут:
   качаются маппинги и декомпилируется Minecraft) → внизу страницы рана
   скачай Artifacts → `xevis-1.12.2` → jar положи в папку `mods` клиента
   с Forge 1.12.2.

Повторные сборки запускаются сами при каждом пуше, либо вручную:
Actions → build-forge-1.12.2 → Run workflow.

**Локально (без IDEA, командной строкой):** нужны строго JDK 8 и Gradle 4.9
(ForgeGradle 2.3 не запускается на новых Gradle; ошибка
`Could not find method jcenter()` означает Gradle 8/9 — он не подойдёт):

```bat
set JAVA_HOME=C:\путь\к\jdk8
C:\путь\к\gradle-4.9\bin\gradle.bat build
```

Готовый jar: `build/libs/xevis-0.2.8.jar` → положить в папку `mods` клиента
с установленным Forge 1.12.2 (рекомендуется `14.23.5.2768` —
у более новых сборок 2855/2860 с мавен-форджа пропал userdev-файл,
поэтому сборка пинится на 2768; на код мода это не влияет).

Пины версий: `minecraft 1.12.2`, `mappings snapshot_20171003`,
`forge 14.23.5.2768`. Код написан под эти маппинги (MCP-имена).

## Настройка

После первого запуска появится `config/xevis.json`: префикс/клан/подпись
и их цвета, масштаб ников, список голограмм (координаты — командой `/xeholo`,
стиль — с сайта кнопкой «Отправить PNG в игру»).
Без сайта: тексты правятся в json, применяются после перезахода в мир.

## Честные отличия от Fabric-версии

- Вид тот же, но рендер через старый GL-пайплайн (`FontRenderer`,
  `GlStateManager`, `Tessellator`), поэтому тонкие различия в сглаживании
  шрифта возможны.
- Символы вроде `◆` рисуются системным unicode-шрифтом 1.12.2: если в клиенте
  выключен unicode-font и глифа нет — будет «пустышка». При проблеме замените
  маркер на `>` в конфиге.
- Перекраска чата в игре, как и во Fabric-версии, не делается: настоящий чат
  идёт с сервера, для него нужен серверный плагин. Чат-блок редактора — превью.
